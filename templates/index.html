⚙️ Retrieval-Augmented Generation (RAG) + Local Ollama Architecture

Step 1: Verified Knowledge Base

38 verified campus FAQ entries & official document sections with recorded sources (JSON, CSV, TXT).

Step 2: NLP Preprocessing

Unicode normalization, contraction handling, campus abbreviation expansion (BSCS, LMS, HoD, FYP), & stopword filtering.

Step 3: Pretrained Embeddings

Dense vector representation of passages and student queries via Ollama's local embedding API ({{ active_embed_model }}).

Step 4: Cosine Similarity Retrieval

Computes vector cosine similarity $\cos(\theta) = \frac{\mathbf{q}\cdot\mathbf{d}}{\|\mathbf{q}\|\|\mathbf{d}\|}$ and checks relevance threshold to filter out-of-scope queries.

Step 5: Grounded Ollama LLM

Passes Top-K retrieved passages to the local Ollama LLM ({{ active_llm_model }}) to synthesize a source-cited answer or abstain.
